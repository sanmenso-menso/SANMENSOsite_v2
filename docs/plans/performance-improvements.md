# 処理負荷の改善

STANDARD。2026-10-08の監査を基準に、演出、音質、公開データと既存サイトの操作を保ったまま修正する。

1. 音楽プレイヤーの音源を再生操作まで取得しない。WebGLをUIから遅延読み込みし、曲変更時にシーンを再作成しない。
2. 一覧とプロフィールの画像に複数サイズを生成する。原本を維持し、同期・ビルドでも継続生成する。
3. Works読み込み前後のレイアウトシフトを観測し、背景と本文の配置を安定化する。
4. 立方体の数学依存を分離し、静止時の更新を止める。非表示・画面外の描画、停止中のレーン・プレイヤー描画を抑える。
5. 画像・音声・描画の回帰テスト、全体check、依存監査、ブラウザで再生・遷移・演出確認、本番反映後の再計測。

監査の仮説: (1)音源の先読みを止めれば初期転送量が減る、(2)共通Three.jsを分離すればトップの初期JSが減る、(3)データ取得で本文高さが変わるなら読み込み領域の確保でCLSが減る、(4)背景のサイズ基準が変わるなら固定した配置で背景CLSが減る。個別に測定する。最終確認結果は完了時に記録する。
